Detailed Description

Класс игры "Крестики-нолики" (Tic-Tac-Toe).

Реализует консольную игру для двух игроков на поле 3x3. Игрок A играет символом 'O', игрок B — символом 'X'.

Note
Поле хранится как двумерный массив символов char[3][3].
Warning
Класс не поддерживает игру против компьютера.
