\doxysubsection{Detailed Description}
Класс игры "{}Крестики-\/нолики"{} (Tic-\/\+Tac-\/\+Toe). 

Реализует консольную игру для двух игроков на поле 3x3. Игрок A играет символом \textquotesingle{}O\textquotesingle{}, игрок B — символом \textquotesingle{}X\textquotesingle{}.

\begin{DoxyNote}{Note}
Поле хранится как двумерный массив символов {\ttfamily char}\+[3]\+[3]. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Класс не поддерживает игру против компьютера. 
\end{DoxyWarning}
